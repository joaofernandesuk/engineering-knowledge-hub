# 0.1.0 release notes draft

Early preview for local, single-user use. The release combines optional Graphify code intelligence with an ordinary Markdown vault. Project lifecycle actions use a native host agent; the web container stays read-only. No telemetry or AI credentials are required.

Known limitations: path-entry onboarding, no browser note editing, macOS/Linux focus, Windows untested, optional Graphify CLI compatibility, and no remote/multi-user mode. There is no previous public version to upgrade from. Do not publish until the final privacy, license, clean-install, and migration review is accepted.
