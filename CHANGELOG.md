# Changelog

## 0.1.0 — early preview (2026-09-23)

- Separate public-safe product source from private runtime state.
- Browser project onboarding, validation preview, graph update, knowledge scaffold, settings, and unregister/re-add.
- Read-only FastAPI container with React UI and SQLite FTS5 search.
- Native Python host agent with Unix socket or authenticated localhost polling on Docker Desktop.
- Synthetic demo, security model, installation and backup documentation.

No prior public version or upgrade path exists. Existing private prototype installations require a separately tested migration and should not be overwritten in place.

See [the v0.1.0 release notes](docs/RELEASE_NOTES_0.1.0.md) for installation, security boundaries, and known limitations.
